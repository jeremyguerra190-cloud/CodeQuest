Desktop installer availability

The website is ready to link to desktop installers, but the actual installer files are not included in this source ZIP yet. Build them on their target platforms, then upload them into downloads/. The buttons will work after the matching files are hosted here.

How the desktop download works

  1. Open the project in Visual Studio Code.
  2. Run npm install, then npm run check:all.
  3. Build on the target operating system with npm run build:win, npm run build:mac, or npm run build:linux.
  4. Upload the resulting installer to website/downloads/ using the exact filename shown above, then publish the website folder.

Builds for macOS and Windows may require building on the respective operating system. Test each installer before sharing it publicly.
